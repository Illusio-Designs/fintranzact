Fintranzact supports keyboard shortcuts in the **web app** and the **desktop app** to speed up your workflow. They are not available in the mobile app.

:::tip[See the list inside the app]
Press <kbd>?</kbd> (<kbd>Shift</kbd>+<kbd>/</kbd>) anywhere in the app to open the **Keyboard Shortcuts** dialog. It lists every shortcut that is active on the page you are on, including page-specific ones.
:::

## Global shortcuts

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on Mac) | Open the command palette |
| <kbd>/</kbd> | Open the command palette (search) |
| <kbd>?</kbd> | Show or hide the **Keyboard Shortcuts** dialog |

<kbd>Ctrl</kbd>+<kbd>K</kbd> works even while your cursor is in a text field. <kbd>/</kbd> and <kbd>?</kbd> are ignored while you are typing in a field.

## Navigation: press G, then a key

Navigation uses two-key sequences: press <kbd>G</kbd>, release it, then press the second key within about 1.5 seconds. For example, <kbd>G</kbd> then <kbd>I</kbd> opens Invoices.

| Sequence | Opens |
|---|---|
| <kbd>G</kbd> then <kbd>D</kbd> | Dashboard |
| <kbd>G</kbd> then <kbd>I</kbd> | Invoices |
| <kbd>G</kbd> then <kbd>Q</kbd> | Quotations |
| <kbd>G</kbd> then <kbd>C</kbd> | Credit Notes |
| <kbd>G</kbd> then <kbd>P</kbd> | Parties |
| <kbd>G</kbd> then <kbd>T</kbd> | Items |
| <kbd>G</kbd> then <kbd>M</kbd> | Payments |
| <kbd>G</kbd> then <kbd>B</kbd> | Cash & Bank |
| <kbd>G</kbd> then <kbd>E</kbd> | Expenses |
| <kbd>G</kbd> then <kbd>G</kbd> | GST Returns |
| <kbd>G</kbd> then <kbd>R</kbd> | Business Reports |
| <kbd>G</kbd> then <kbd>S</kbd> | Settings |

:::note
Sequences only work when the cursor is not in a text field, and neither key may be held together with <kbd>Ctrl</kbd>, <kbd>Alt</kbd>, or <kbd>⌘</kbd>. Click an empty area of the page first.
:::

### Alt+Shift aliases

The older <kbd>Alt</kbd>+<kbd>Shift</kbd>+key chords still work as aliases for the same pages, using the same letters as the table above — for example <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> for Invoices and <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> for Settings. Unlike the sequences, these chords also work while the cursor is in a text field.

:::caution
The G-sequences are the recommended shortcuts. On Windows, <kbd>Alt</kbd>+<kbd>Shift</kbd> switches the input language when more than one keyboard layout is installed, so the chord never reaches Fintranzact. On a Mac, <kbd>Option</kbd>+<kbd>Shift</kbd>+letter types a special character instead of the letter, so the aliases generally do not work there.
:::

## Page shortcuts

On these list pages, press <kbd>N</kbd> (outside a text field) to start a new record:

| Page | <kbd>N</kbd> opens |
|---|---|
| Invoices | New invoice |
| Parties | New party |
| Items | New item |
| Payments | Record new payment |
| Expenses | New expense |
| Journal Entries | New journal entry |
| Recurring Invoices | New recurring invoice template (listed as "New automated invoice" in the shortcuts dialog) |

The point-of-sale register has its own set of cashier shortcuts (search, customer, pay, parked carts). See [Point of Sale](/help/pos).

## Frequently asked questions

**Nothing happens when I press G then I. Why?**
Your cursor is probably inside a text field (a search box or form input). Sequences are ignored while you type, so that typing the letter "g" in a party name doesn't navigate away. Click an empty area of the page, then try again. Also make sure you press the second key within about 1.5 seconds.

**Can I customise the shortcuts?**
No. The shortcuts are fixed in the current version.

**Do shortcuts work in the desktop app?**
Yes. The desktop app uses the same screens as the web app, so every shortcut on this page works there too.
